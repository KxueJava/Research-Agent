状态：待验收。2026-10-21 用户确认暂无 Android/iPhone 真机。
桌面 390/768 视口、鼠标触控模拟和本机 GPU 数据不算手机通过。

## 准备

1. 手机与电脑连接同一可信局域网。使用实际可访问的部署地址打开项目；手机上的 localhost 指手机自身。
2. 确认该地址下前端、API、文件预览与地图域名白名单均正确，使用测试账号登录。不要向公网开放开发服务来绕过局域网问题。
3. 记录手机型号、系统/浏览器版本、网络、全局主题和构建版本。截图或录像不得包含凭证、个人对话或真实用户文件。

## 实际项目检查

从项目聊天页逐项操作，不以独立静态演示页替代：

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 地图 | 打开路线、拖动/缩放、选择地点、打开简介、全屏返回、旋转屏幕 | 地点与列表一致；简介可读；视口符合既定策略；控件可触达 |
| 地图资源 | 连续打开/关闭 20 次，停留 10 分钟 | 无崩溃/持续卡顿；有可审阅的浏览器/系统资源记录 |
| HTML 游戏 | 开始、触屏操作、暂停、切换容器、返回、重新运行 | 暂停及容器切换符合生命周期；重新运行明确重置 |
| 数据分析 | 上传合成 sales.csv，筛选、排序、选中、刷新 | 数值对照 sales-expected.json；刷新恢复；操作不启动 Agent |
| 远程动作 | 双击、断网、恢复网络、查询结果、取消 | 不重复执行；失败不报成功；取消不谎报外部回滚 |
| 研究/表单/分账 | 修改原 Surface、刷新；人数 0/负值/小数金额 | 无横向溢出；焦点可见；错误可恢复；敏感输入不恢复 |
| 网络 | Wi-Fi 与蜂窝切换、短时飞行模式后重连 | 登录/数据恢复；无重复已完成动作；失败有明确反馈 |

每项记录开始/结束时间、实际结果与证据路径。失败保持未通过，修复后重跑对应场景。
真实模型生成仍受默认模型凭证 401 阻塞；固定数据界面操作不替代该项。

## 本机证据的边界

`browser-native-soak.jsonl` 为专属 Playwright 浏览器进程树的原生采样，包含 private/working-set、句柄、线程及 GPU dedicated/shared usage。
`native-resource-result.json` 汇总该记录。首次长浏览器调用达到 300 秒工具超时，结构化循环结果没有完整返回；随后单独确认创建/销毁计数及清理后 JS 堆。因此保留观察结果，不标为完整长时性能通过，也不设置未经基线支持的性能承诺。
