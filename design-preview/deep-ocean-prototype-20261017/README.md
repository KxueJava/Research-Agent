# Research-Agent 深海液态玻璃交互原型

这是供视觉与交互评审使用的独立原型，不是正式应用，也没有替换项目页面。所有新增文件均在本目录中，未修改 `ui/src`、后端、路由或 API。

## 打开

- 双击 `index.html` 即可在支持 JavaScript 的现代浏览器中打开。
- 当前本地预览地址：`http://127.0.0.1:4178/`。
- HTML 已内嵌 Three.js、字体、CSS、脚本和矢量示意图，不依赖 CDN，不需要安装依赖或连接后端。

## 页面与入口

| 页面 / 状态 | 入口 |
| --- | --- |
| 欢迎页 | 对话 / 新建任务 |
| 对话、Agent 执行、报告工作区 | 历史任务，或发送一个问题 |
| MRAG 与知识库 | MRAG |
| 图片生成、预览与选区编辑 | 生图 |
| 子 Agent 配置 | 子 Agent |
| 模型配置 | 模型 |
| MCP / Skill 管理 | 能力库 |
| 精选案例回放 | 精品对话 |
| 统计与 CSV 导出 | 用量统计 |
| SOP 流程 | 用户菜单 → 原型导航与显示 → SOP |
| 个人资料、外观、安全表单 | 左下头像 → 账号设置 |
| 登录与注册表单 | 用户菜单 → 退出登录，或原型导航 → 登录 |

原型导航可从用户菜单或页面右上设置按钮打开。它是评审用工具，不是新增的正式产品功能。

## 可体验的交互

- 左侧导航、任务搜索、置顶、删除、用户菜单及移动端抽屉。
- 深色深海 / 浅色浅海主题；自动、低动态、静态背景选项。
- 推荐问题回填，多轮对话演示，执行模式与模型选择，附件状态，任务停止与重新生成。
- Agent 步骤展开；报告、代码和来源切换；报告图表切换；工作区拖动和键盘调整宽度；HTML 下载。
- 创建和选择知识库、添加网页条目、文件选择状态、查看示例正文、示例问答和删除确认。
- 图片生成流程、比例选项、预览、本地涂抹选区、编辑描述与 SVG 下载。
- 模型与子 Agent 的新增、编辑、开关和表单校验；MCP / Skill 配置和启停。
- 统计周期切换、案例筛选与回放、SOP 任务入口、登录 / 注册校验。
- 弹窗 Esc 关闭、焦点约束、Enter 发送、Shift + Enter 换行。

## 演示边界

- 没有调用 LLM、Embedding、Qdrant、MCP、图像生成或鉴权服务。
- “生成”和“执行”由本地定时器演示。所有结论、来源、统计和图像均为明确标注的示例。
- 添加网址不抓取网页；选择文件不上传、不读取文件正文；知识库正文是内置演示文本。
- 图片是程序绘制的 SVG；选区涂抹可以操作，“应用修改”不产生真实 AI 编辑结果。
- 模型“测试连接”仅校验本地字段，不声称连接成功。请勿填写真实 API Key 或真实密码；凭据不会保存或发送。
- 主题、画质、演示用户名及演示知识库保存在独立的 `ocean-prototype-*` localStorage 键中。模型、Agent、对话和图片仅保留到当前页面刷新。
- 此处没有复用生产鉴权或业务状态；它不用于验证真实 API、权限、安全性或业务正确性。

## 视觉与布局基准

- 沿用真实源码的侧栏 280px、首页输入区最大 920px、消息阅读区与右侧工作区组织。
- 保留真实导航名称、顺序和主要控件层次。欢迎页使用现有轮播标题之一 “Let's research”。
- 采用现有 Instrument Sans 字体；中文使用系统中文字体回退。
- 玻璃强度区分导航、输入框、浮层、阅读内容；报告 iframe 保持自身浅色排版，不套玻璃主题。
- 原型没有嵌入生产 React DOM；未进行与真实应用的 1–2px 坐标一致性验收。正式实施仍需建立真实页面截图与 DOM 坐标基线。

## 性能与兼容性限制

- 单个 Three.js 全屏平面 Shader，桌面绘制上限 30 FPS，低动态 / 移动设备上限 24 FPS；DPR 限制为 1–1.35。
- 隐藏页面暂停渲染；减少动画或 WebGL 出错时回退到 CSS 渐变。恢复上下文时释放旧材质、几何与 Renderer。
- 上述 FPS 是程序上限，不是跨设备实测性能。尚未完成真实移动设备、Firefox、Safari、长时间运行和 GPU 内存分析。
- 毛玻璃依赖浏览器支持；不支持 `backdrop-filter` 时主要浮层回退到更高不透明度。

## 源文件

`shell.html`、`ocean.css`、`liquid-glass.css`、`ocean.js`、`prototype.js`、`views.js` 和 `interactions.js` 是原型源文件。`build.py` 将它们及项目已安装的 Three.js、字体打包为单文件 HTML。

重新生成：

```powershell
python design-preview/deep-ocean-prototype-20261017/build.py
```

与正式项目的样式、依赖及打包配置相互独立。
